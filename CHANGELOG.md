# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Repository hygiene overhaul: MIT License, repository metadata.
- Linter and formatter tooling: ESLint (`.eslintrc.cjs`), Prettier (`.prettierrc.cjs`), Ruff (`.ruff.toml`), and Black config.
- Monorepo package scripts for lint, format, typecheck, test, and coverage.
- Vitest configuration (`vitest.config.ts`) for frontend testing.
- GitHub Actions CI workflows for linting (`lint.yml`), testing (`test.yml`), and building (`build.yml`).
- Centralized documentation directory (`docs/`) housing phase summaries and build plans.
- MkDocs configuration (`mkdocs.yml`) for unified documentation.

## [0.1.0] - 2026-11-19
- Initial repository setup and architecture implementation (Phases 1 through 5).
